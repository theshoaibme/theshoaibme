# DevPortfolio

> **A modern, fully responsive developer portfolio.**

[![Homepage](https://s0.wp.com/mshots/v1/https://the-shoaib2.github.io/#hero)](https://the-shoaib2.github.io/#hero)

---

## ✨ Features

- 📱 **Fully Responsive** — Looks great on any device.
- 🎨 **Modern UI** — Clean layout with smooth animations.
- 🚀 **High Performance** — Lightweight and fast.
- 🌗 **Themable** — Easy to customize colors and style.
- 📄 **Dynamic Content** — Manage all text and projects via a single `data.json` file.

## ⚙️ Configuration

| File | Purpose |
| :--- | :--- |
| **`data.json`** | **Start Here!** Edit your name, links, projects, and skills. |
| **`style.css`** | Modify colors in `:root` to match your brand. |
| **`index.html`** | Structure and layout (rarely needs editing). |
